\section{Reglas generales}
\begin{itemize}
  \item Cada jugador o equipo debe registrar un nickname.
  \item No se debe usar el nickname de otro estudiante.
  \item El juez es quien inicia, detiene o reinicia cada partida.
  \item Hay que esperar la confirmación en pantalla antes de volver a pulsar.
  \item Se debe respetar a los demás jugadores y aceptar el resultado.
  \item Si algo no funciona, hay que avisar al estudiante encargado o al juez, sin pulsar muchas veces.
\end{itemize}

\juego{Juego del 80\%}

\subtitulo{Explicación corta para los estudiantes}
\begin{tcolorbox}[colback=gris,colframe=dorado]
Cada jugador, o cada pareja, escoge un número entre 0 y 20. Cuando todos responden, gana la ronda quien queda más cerca del 80\% del promedio. Cada ronda ganada vale un punto.
\end{tcolorbox}

\subtitulo{Cómo se juega}
\begin{enumerate}
  \item El juez anuncia si la partida será individual o por parejas.
  \item Escribe tu nickname y entra a la partida.
  \item Espera a que el juez abra la ronda.
  \item Elige un número entre 0 y 20, o acuerdalo con tu pareja.
  \item Espera a que todos respondan.
  \item El juez cierra la ronda y entrega un punto al ganador o a los ganadores empatados.
  \item Se juegan hasta seis rondas.
\end{enumerate}

\subtitulo{Importante}
\begin{itemize}
  \item Solo se puede enviar un número por ronda.
  \item No cambies tu respuesta después de enviarla.
  \item El objetivo de cada ronda aparece cuando el juez cierra la ronda.
  \item Gana la ronda el número más cercano al 80\% del promedio.
  \item Si hay empate, todos los empatados reciben un punto.
  \item Al terminar las seis rondas, gana el jugador o la pareja con más puntos.
  \item El juez puede repetir la partida con el mismo grupo o con estudiantes que aún no hayan jugado.
  \item La modalidad y los integrantes de cada pareja deben anunciarse antes de comenzar.
\end{itemize}

\juego{Código Maestro}

\subtitulo{Explicación corta para los estudiantes}
\begin{tcolorbox}[colback=gris,colframe=dorado]
Cada equipo intenta descubrir un código secreto de cuatro cifras. Después de cada intento recibirá pistas para saber qué cifras están correctas o qué cifras aparecen en otra posición.
\end{tcolorbox}

\subtitulo{Cómo se juega}
\begin{enumerate}
  \item Escribe el nombre de tu equipo.
  \item El juez abre el desafío.
  \item Escribe un código de cuatro cifras.
  \item Lee las pistas que aparecen.
  \item Usa la lógica para mejorar el siguiente intento.
  \item Los primeros equipos en descubrir el código ocupan los primeros lugares.
\end{enumerate}

\subtitulo{Importante}
\begin{itemize}
  \item No compartas tu código con otros equipos.
  \item Revisa cada pista antes de volver a intentar.
  \item El juez controla el inicio, las pistas y el reinicio.
  \item Si el equipo ya envió un intento, debe esperar la respuesta del sistema.
\end{itemize}

\juego{Las Cuatro Figuras}

\subtitulo{Explicación corta para los estudiantes}
\begin{tcolorbox}[colback=gris,colframe=rosado]
Cada estudiante recibe una carta de póker boca abajo. El número de la carta se registra en el juego, pero la figura permanece oculta. Luego debe adivinar si su carta es de picas, corazones, tréboles o diamantes.
\end{tcolorbox}

\subtitulo{Cómo se juega}
\begin{enumerate}
  \item Escribe tu nickname y entra a la partida.
  \item Recibe una carta de póker boca abajo.
  \item Mira el número de la carta en la cara que corresponde al registro y escríbelo en el juego.
  \item Espera mientras los demás jugadores registran sus cartas.
  \item Elige una de las cuatro figuras: picas, corazones, tréboles o diamantes.
  \item Si necesitas ayuda, consulta a otro jugador.
  \item El jugador consultado ve la figura real y puede decir la verdad, engañar o no decir nada.
  \item Cuando el juez cierre el tiempo, todos deben haber elegido una figura.
  \item El juez revela la ronda y elimina a quienes no acertaron.
  \item Se recogen las cartas, se entregan cartas nuevas y comienza la siguiente ronda.
  \item Las rondas continúan hasta que quede un solo jugador o equipo activo.
\end{enumerate}

\subtitulo{Las cuatro figuras}
\begin{itemize}
  \item Corazones.
  \item Tréboles.
  \item Diamantes.
  \item Picas.
\end{itemize}

\subtitulo{Importante}
\begin{itemize}
  \item El número de carta debe estar entre 1 y 52.
  \item No se puede repetir un número que otro jugador ya registró.
  \item Escribe el número y espera a que el sistema confirme el registro.
  \item Una consulta permite pedir ayuda a otro jugador, pero su respuesta puede ser verdadera o engañosa.
  \item El jugador consultado también puede responder que no está seguro o no decir nada.
  \item La decisión final es obligatoria antes de que el juez cierre la ronda.
  \item Si la pantalla se actualiza, revisa que tu número siga escrito antes de enviarlo.
  \item Al final de cada ronda las cartas se recogen y se reparten cartas nuevas.
  \item Gana el último jugador o equipo que permanezca activo.
\end{itemize}

\juego{Gana y Elimina}

\subtitulo{Explicación corta para los estudiantes}
\begin{tcolorbox}[colback=gris,colframe=rosado]
El juez hace una pregunta con tiempo limitado. Responde lo más rápido posible. Los mejores resultados reciben protección y el ganador de la ronda obtiene el poder de eliminar a otro jugador.
\end{tcolorbox}

\subtitulo{Cómo se juega}
\begin{enumerate}
  \item Escribe tu nickname.
  \item Espera a que el juez inicie la pregunta.
  \item Lee con atención y responde una sola vez.
  \item Espera la confirmación de respuesta enviada.
  \item El juez cierra la ronda y muestra los primeros lugares.
  \item El ganador puede elegir a quién eliminar, según las reglas de la ronda.
  \item Gana el último jugador que permanezca en juego.
\end{enumerate}

\subtitulo{Importante}
\begin{itemize}
  \item Hay poco tiempo para responder.
  \item Después de pulsar una respuesta, no vuelvas a pulsar: espera la confirmación.
  \item Si el botón se desactiva, significa que tu respuesta ya fue recibida.
  \item Si no respondes a tiempo, puedes quedar eliminado.
  \item El juez puede usar la opción de eliminar al azar si la situación lo requiere.
\end{itemize}

\juego{Pista de Velocidad}

\subtitulo{Explicación corta para los estudiantes}
\begin{tcolorbox}[colback=gris,colframe=azul]
Cada jugador conduce un vehículo en una pista. Debe completar tres vueltas y cruzar la meta. El puesto se asigna en el orden exacto en que cada jugador llega.
\end{tcolorbox}

\subtitulo{Cómo se juega}
\begin{enumerate}
  \item Escribe tu nickname para ocupar un puesto en la parrilla.
  \item Espera a que el juez inicie el semáforo.
  \item Usa las flechas del teclado para acelerar, frenar y girar.
  \item También puedes usar los botones en pantalla.
  \item Completa tres vueltas sin salirte de la pista.
  \item Cruza la meta y espera la posición definitiva.
\end{enumerate}

\subtitulo{Controles}
\begin{itemize}
  \item Flecha arriba: acelerar.
  \item Flecha abajo: frenar o retroceder.
  \item Flecha izquierda: girar a la izquierda.
  \item Flecha derecha: girar a la derecha.
  \item Barra espaciadora: usar el ítem disponible.
\end{itemize}

\subtitulo{Importante}
\begin{itemize}
  \item El primer jugador que cruza la meta obtiene el primer puesto.
  \item Cada puesto se reserva una sola vez.
  \item No abandones la pantalla después de cruzar la meta hasta ver tu posición.
  \item El juez puede reiniciar la carrera y vaciar la sala.
\end{itemize}

\juego{Paintball}

\subtitulo{Explicación corta para los estudiantes}
\begin{tcolorbox}[colback=gris,colframe=verde]
Todos compiten contra todos. Cada jugador aparece alrededor del campo, busca una pelota, se esconde detrás de las barricadas y trata de impactar a los demás. Gana el último jugador que siga en pie.
\end{tcolorbox}

\subtitulo{Cómo se juega}
\begin{enumerate}
  \item Escribe tu nickname y espera la orden del juez.
  \item Al comenzar, busca una pelota roja en el campo.
  \item Acércate a la pelota para recogerla automáticamente.
  \item Usa el mouse para mover la mira.
  \item Mantén presionada la barra espaciadora para avanzar.
  \item Pulsa \texttt{Alt} para saltar.
  \item Haz clic izquierdo para lanzar la pelota.
  \item Usa las barricadas para esconderte y contraatacar.
\end{enumerate}

\subtitulo{Importante}
\begin{itemize}
  \item Nadie empieza con una pelota.
  \item Las pelotas se recogen al pasar cerca de ellas.
  \item Las barricadas bloquean al jugador y las pelotas.
  \item Las barricadas bajas permiten asomarse y contraatacar.
  \item Las barricadas altas sirven para esconderse.
  \item Tres impactos eliminan a un jugador.
  \item Gana el último jugador vivo.
  \item El juez controla el registro, el inicio y el reinicio de la partida.
\end{itemize}

\section{Frases útiles para los encargados}

\subtitulo{Antes de comenzar}
\begin{tcolorbox}[colback=gris,colframe=azul]
Escribe tu nickname y espera la orden del juez. Si algo no aparece, avísanos y no pulses muchas veces.
\end{tcolorbox}

\subtitulo{Cuando un estudiante no entiende}
\begin{tcolorbox}[colback=gris,colframe=azul]
Primero mira el objetivo. Después pulsa una sola vez. Finalmente espera la confirmación en pantalla.
\end{tcolorbox}

\subtitulo{Cuando termina una respuesta}
\begin{tcolorbox}[colback=gris,colframe=verde]
Ya quedó registrado. Espera la siguiente instrucción.
\end{tcolorbox}

\subtitulo{Si hay un problema}
\begin{tcolorbox}[colback=gris,colframe=rosado]
No cierres la página. Llama al encargado para revisar tu registro.
\end{tcolorbox}

\subtitulo{Para terminar}
\begin{tcolorbox}[colback=gris,colframe=azul]
Gracias por participar. Recuerda aceptar el resultado y dejar el puesto para el siguiente grupo.
\end{tcolorbox}
